# Trend Analysis Methodology

## Purpose

This document defines how AI should analyze manufacturing trends over time.

The objective is not to compare isolated values.

The objective is to determine whether manufacturing performance is improving, deteriorating or remaining stable.

Trend analysis shall support early decision making before problems become critical.

---

# Core Principle

A single abnormal value is not a trend.

A trend requires data over time.

Always evaluate direction, consistency and variation.

Never make conclusions from one isolated production run.

---

# Business Interpretation

Every trend should answer

What changed?

When did it change?

Why did it change?

Is the change temporary or permanent?

Does it require management intervention?

Can future performance be predicted?

---

# Early Warning Indicators

The AI should identify

Rapid increase in Burned

Rapid increase in Startup Scrap

Increasing Purge Weight

Increasing Reject Rate

Increasing Process Variation

Repeated abnormal production days

Declining machine stability

Repeated quality failures

These indicators should be highlighted before they become major losses.

# Management Questions

Every trend analysis should answer

Is factory performance improving?

Which department is improving fastest?

Which machines are becoming unstable?

Which products require attention?

Are corrective actions working?

Where should management intervene next?

---

# Golden Rules

Never compare trends without using the same KPI.

Always separate Engineering Scrap from Operational Scrap.

Always normalize by production volume.

Always distinguish between common variation and abnormal variation.

Trend analysis should guide future decisions, not only explain past performance.
