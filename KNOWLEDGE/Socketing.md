# Socketing Department Knowledge Base

## Purpose

The Socketing Department performs the final socket forming operation on thermoplastic pipes after extrusion.

This process is applicable to:
- U-PVC Pipes
- PP-H Pipes (when required)
- PP-R Pipes
- PP-R UV Pipes
- PP-R Multilayer Pipes

The quality of the socket directly affects pipe assembly, sealing performance and customer satisfaction.

# Main Objectives

- Produce socket dimensions within specification.
- Maintain concentricity.
- Prevent deformation.
- Prevent cracks.
- Ensure proper insertion depth.
- Ensure correct appearance.

# Root Causes

Possible causes include:

## Machine

- Heater malfunction
- Temperature instability
- Worn forming tools
- Improper cooling

## Material

- Incorrect pipe temperature
- Material instability
- High recycled material ratio

## Method

- Incorrect heating time
- Incorrect forming cycle
- Improper cooling sequence

## Man

- Incorrect machine setup
- Poor handling
- Failure to follow SOP

# Engineering Notes

Socket defects should be analyzed separately from extrusion defects.

Do not combine extrusion scrap with socket scrap during root cause analysis.

The socketing department should have independent performance indicators because extrusion may be stable while socket forming introduces additional defects.

Always identify whether the defect originated during:

- Extrusion
- Socket Heating
- Socket Forming
- Cooling
- Handling

Correct classification improves root cause accuracy.
